# 🌟 英文現在簡單式互動學習網頁 (Present Simple Quest)

專為國小與國中學生設計的互動式英文文法教學網頁，透過視覺動畫、合成音效、真人英語發音與趣味闖關遊戲，輕鬆搞懂「現在簡單式（Present Simple Tense）」！

---

## 🚀 如何開啟學習網頁

有以下幾種最簡單的開啟方式：

1. **直接連點兩下快捷檔（macOS 推薦）**：
   - 在本資料夾中，直接雙擊滑鼠左鍵點開 `啟動網頁.command`，系統將自動以預設瀏覽器打開！
2. **直接點開網頁檔**：
   - 雙擊本資料夾中的 `index.html` 即可直接在瀏覽器執行（本網頁為純前端架構，無須安裝任何後端依賴）。
3. **終端機指令開啟**：
   ```bash
   open "/Users/chentang/Documents/antigravity/Present Simple Tense/index.html"
   ```

## 🎮 五大功能特色

1. **📖 觀念實驗室 (Concept Lab)**：
   - 圖解「日常習慣、客觀真理、喜好感受」三大情境。
   - 頻率副詞（always, usually, sometimes, never）圖表。
   - 即時互動判斷題（檢驗句子是否為簡單式）。
2. **⚙️ 三單變形實驗室 (The Verb Transformer)**：
   - 互動拉桿變形機：輸入任何英文動詞，即時分析動詞字尾（-s, -es, -ies, has）與記憶口訣。
3. **👾 Doesn't 大胃王怪獸 (The S-Monster)**：
   - 肯定句 ➔ 否定句 ➔ 疑問句動態切換，直觀展示怪獸如何吃掉動詞的 `-s`，加深「助動詞後面動詞打回原形」的印象！
4. **🕹️ 四大闖關遊戲區 (Game Arcade)**：
   - **動詞抓抓樂**：30秒主詞動詞極速速配與連擊計分！
   - **變形敲敲樂**：動詞字尾分類傳送門挑戰！
   - **句子大拼圖**：單字積木點選組裝！
   - **魔法大考驗**：綜合 10 題關卡與愛心血量評分！
5. **📜 學習秘笈與一頁紙列印單 (Worksheet & Cheatsheet)**：
   - 包含文法總整理、四大口訣，以及 10 題隨堂測驗練習單，支援一鍵列印！
